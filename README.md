# 仿真优化与人工智能 · 网页版

[中文阅读](https://rtkenny.github.io/so-ai-book/?lang=zh) · [Read in English](https://rtkenny.github.io/so-ai-book/?lang=en)

本仓库保存《Simulation Optimization and Artificial Intelligence》的静态网页版，包含 6 章中英双语导读及完整正文、参考文献、致谢、4 个双语 Hands-on Lab、实验配图和可下载的 Python 代码。

桌面侧栏和手机顶栏可切换中文 / English。导航、导读、完整正文、致谢、实验说明、图注和代码复制提示随语言切换，并记住阅读偏好。点击章节导读下方的“展开章节全文”即可阅读对应语言的完整书稿。`?lang=zh` 和 `?lang=en` 可用于分享指定语言的链接。

中文正文包含 762 个翻译内容块，由机器翻译生成，并校订了标题、图注、部分段落和专业术语。每章均提供译文说明，可随时切换英文对照。公式、代码、参考文献的书目信息、原书插图内的标签和原书 PDF 保留原样。

Use the language buttons in the sidebar or mobile header to switch between Chinese and English. All six complete chapters, chapter guides, acknowledgments, lab instructions, captions, and interface text are bilingual. Expand “Read the full chapter” below a guide to read the full text. Chinese manuscript translations are machine-generated with selected passages and terminology reviewed. Equations, code, bibliographic records, labels embedded in original figures, and the original English PDF are preserved.

## 浏览

打开在线阅读地址，或下载整个仓库后用浏览器打开 `index.html`。公式、图片和字体资源保存在本地，无需安装 Node.js 或 Python 即可阅读。

实验脚本位于 `downloads/code/`，使用电脑上的 Python 3.9+ 运行；网页提供实验说明和代码下载。

## 部署与更新

GitHub Pages 从 `main` 分支的根目录发布。仓库根目录的 `.nojekyll` 文件让 GitHub 直接发布静态文件。

更新生成后的 `index.html`、`assets/` 和 `downloads/`，提交并推送到 `main` 后，GitHub Pages 会自动更新网站。LaTeX 原稿和本地构建环境单独维护。

MathJax 的许可证保存在 `assets/vendor/mathjax/LICENSE`。
